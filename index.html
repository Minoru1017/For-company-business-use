還沒有 DEMO 逐字稿？本機轉錄指引（1～2 小時錄影・不上雲）

DEMO 錄影需先在公司電腦本機轉成 SRT，再回來上傳分析。音檔不會上傳至任何雲端服務。

  1. 從 GitHub 下載整個 demo-workspace 資料夾到本機（見下方結構）
  2. 依操作手冊用 CMD 轉錄 MP4 → 取得 output\*.srt
  3. 將 SRT 拖曳到上方上傳區 → 確認 SPEAKER_00＝顧問

資料夾結構（全部放在同一層，不要拆散）

C:\Users\經銷業務\demo-workspace\
├── input\              ← 放 DEMO 錄影（demo.mp4）
├── output\             ← 轉完在這裡取 .srt
├── .env                ← HF_TOKEN（勿分享）
├── setup_demo.py       ← 第一次：python setup_demo.py
├── transcribe_demo.py  ← 每次轉錄：python transcribe_demo.py

HF_TOKEN 取得方式（首次設定，約 5 分鐘）

用於 WhisperX「誰在說話」分軌。Token 只寫在本機 .env，不會上傳到 Call Coach。

  1. 註冊 Hugging Face 帳號：huggingface.co/join
  2. 建立 Read Token：Settings → Access Tokens → 點 New token → Type 選 Read → 複製（開頭 hf_，只顯示一次）
  3. 同意三個模型授權（同一帳號登入，各頁按 Agree）： community-1、 diarization-3.1、 segmentation-3.0
  4. 用記事本開啟 demo-workspace\.env，填入一行（等號前後不要空格、不要引號）：
    HF_TOKEN=hf_貼上你的token
開啟 CMD 操作手冊（完整版） demo-workspace 資料夾 ｜ 電訪用 Vibe 檢查清單（<20 分鐘）

轉錄約需 1.5～3 小時（CPU 筆電），請接電源。路徑請用 .venv\Scripts\whisperx.exe（不是 Scripts\）。
