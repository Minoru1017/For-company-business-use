# 分頁用途標記

一個不需要伺服器、帳號或外部套件的 Chrome／Microsoft Edge 擴充功能。除了替分頁加上用途，也會把新分頁改成多領域 16 格網站首頁。

- 分頁標題前綴，例如 `【待回覆】 公司信箱`
- 工具列圖示上的 2 字徽章
- 擴充功能內的分頁清單與用途顏色
- 16 個可拖曳排序的網站縮圖槽
- 工作／興趣／影視與自訂領域，每個領域各有 16 槽
- 空槽導入網站時會帶入放大的 LOGO 縮圖
- 首頁可登入／顯示目前 Google 帳號
- 點選槽位以內嵌浮動視窗開啟，不另開新視窗；支援左右分屏與拖曳縮放
- 首頁顯示目前開啟的網站分頁，可拖入空槽
- 網站群組、例行公事流程與步驟順位

## 安裝到公司電腦

1. 下載 `tab-purpose-extension.zip` 並解壓縮。
2. Chrome 開啟 `chrome://extensions`；Edge 開啟 `edge://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 按「載入未封裝項目」，選擇解壓縮後的 `tab-purpose-extension` 資料夾。
5. 將「分頁用途標記」固定到工具列。

公司若停用「開發人員模式」，需請資訊人員透過 Chrome Enterprise 或 Edge 管理中心部署擴充功能。這是瀏覽器的公司政策限制，無法由擴充功能繞過。

## 使用方式

1. 打開要標記的分頁。
2. 點工具列上的擴充功能。
3. 輸入用途後按「套用」，或直接點常用用途。
4. 從下方清單搜尋、查看並切換所有開啟的分頁。

## 多領域 16 格網站首頁

安裝後，開啟新分頁就會看到網站首頁：

1. 先選「工作／興趣／影視」，或按「＋新領域」建立旅遊、閱讀等自訂領域。
2. 右上角可登入 Google 帳號（讀取瀏覽器目前登入的 Google 身分）。
3. 首頁頂部會列出這個瀏覽器視窗目前開啟的網站分頁；把項目拖到空槽，或按項目右側的 `＋`，空槽會顯示放大的網站 LOGO。
4. 也可在任一網站點擴充功能，再按「存到首頁」，系統會擷取輕量縮圖並放入目前領域的第一個空槽。
5. 從其他視窗拖曳網頁連結到空槽也能新增；Chrome 本身的分頁列不能可靠地直接拖進網頁，因此請使用首頁提供的分頁列。
6. 點槽位預覽會以內嵌浮動視窗開啟網站；再點另一個槽位可左右分屏，拖曳中間分隔線縮放。部分網站禁止內嵌時，可用「另開分頁」。
7. 點卡片右側的編輯按鈕，可設定網站名稱、群組、例行流程與流程順位。
8. 用卡片箭頭或拖曳調整 1～16 的首頁位置；流程仍依設定的步驟順位執行。
9. 用首頁右上方的流程選單選擇例行公事，再按「開始流程」，網站會依順位開啟。

首頁只能讀取目前已開啟的分頁。Google 帳戶在其他裝置同步、但尚未在這個瀏覽器開啟的分頁，不一定會由瀏覽器提供給擴充功能。

若不想讓網站首頁取代新分頁，可到 `chrome://extensions` 或 `edge://extensions` 暫停／移除擴充功能。

標記跟著目前分頁存在，重新整理後仍會保留；關閉分頁時會自動清除。`chrome://`、`edge://`、擴充功能商店等瀏覽器內建頁面禁止修改標題，但工具列徽章與清單標記仍可使用。

## 隱私與資源

- 分頁標記存在瀏覽器工作階段；首頁設定與縮圖存在本機 `chrome.storage.local`。
- LOGO 縮圖會向 Google Favicon 服務請求公開圖示；Google 登入只讀取瀏覽器目前登入的帳號資訊。
- 不含追蹤碼，不讀取網頁內容。
- 縮圖只在你按「存到首頁」時擷取目前可見畫面，壓縮為 320 × 180 JPEG。
- 使用原生 HTML、CSS、JavaScript，沒有執行階段依賴。
- 權限包含 `activeTab`、`identity`、`identity.email`、`scripting`、`storage` 與 `tabs`；程式只在你主動標記的分頁注入標題前綴，不要求全網站常駐權限。

## 打包

在專案根目錄執行：

```bash
npm run package:tab-extension
```

成品會輸出到 `artifacts/tab-purpose-extension.zip`。
