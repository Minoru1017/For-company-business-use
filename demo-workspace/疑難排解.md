# 無法執行？逐步排除

若 `setup.ps1` 或 PowerShell 都無法使用，**請只用 `.cmd` 檔**（命令提示字元批次檔，不受 PowerShell 原則限制）。

---

## 正確做法（不要用 PowerShell 跑 .ps1）

1. 打開 **`demo-workspace` 資料夾**
2. **雙擊 `setup.cmd`**（或右鍵 → 以系統管理員身分執行，通常不需要）
3. 安裝完成後，雙擊 **`transcribe.cmd`**

> 若雙擊後視窗一閃就關閉：在資料夾網址列輸入 `cmd` 按 Enter，再手動輸入 `setup.cmd` 看錯誤訊息。

---

## 錯誤對照表

### 「找不到 python」

1. 安裝 Python：https://www.python.org/downloads/ （建議 3.11）
2. 安裝時**務必勾選** `Add python.exe to PATH`
3. **關閉所有命令提示字元視窗**，重新開啟後再執行 `setup.cmd`

驗證：

```cmd
python --version
```

應顯示 `Python 3.10` 或 `3.11` 以上。

---

### 「已停用指令碼執行」/ PowerShell 錯誤

**不要用** `.\setup.ps1`。

改用：

```cmd
setup.cmd
```

`setup.cmd` 是純批次檔，**完全不經過 PowerShell 腳本**。

---

### 「pip 安裝失敗」/ 網路錯誤

- 確認公司網路是否擋 pip（可試手機熱點）
- 或請 IT 開放 `pypi.org`

---

### 「請在 .env 設定 HF_TOKEN」

1. 用記事本開啟 `demo-workspace\.env`
2. 改成：`HF_TOKEN=hf_你的實際token`（等號兩旁不要空格）
3. 到網頁登入 Hugging Face 並接受授權：  
   https://huggingface.co/pyannote/speaker-diarization-community-1

---

### 完全手動安裝（連 .cmd 都不行時）

在 `demo-workspace` 資料夾開啟**命令提示字元**（cmd），逐行貼上：

```cmd
cd /d C:\Users\經銷業務\demo-workspace

python -m venv .venv

.venv\Scripts\python.exe -m pip install -U pip wheel

.venv\Scripts\python.exe -m pip install whisperx

copy .env.example .env

notepad .env
```

填入 HF_TOKEN 後，放入 `input\demo.mp4`，再執行：

```cmd
transcribe.cmd
```
