# 無法執行？逐步排除

## 請用 .bat 檔，不要用 PowerShell

| 要做的事 | 雙擊這個 |
|---------|---------|
| 第一次安裝 | `安裝.bat` |
| 轉錄（MP4 已在 input） | `一鍵轉錄.bat` |
| 轉錄（拖放 MP4） | `拖放轉錄.bat` |

---

## 常見錯誤

### 找不到 python

安裝 https://www.python.org/downloads/ ，勾選 **Add python.exe to PATH**，重開電腦。

### gated repo / HF_TOKEN

1. `.env` 內：`HF_TOKEN=hf_xxxxx`（無引號、無空格）
2. 同意三個模型頁面（同一 Hugging Face 帳號）
3. 刪除舊 token，重建 Read token 後更新 `.env`

### demo.mp4 找不到

- 確認 MP4 在 `input\` 資料夾
- 若檔名是 `demo.mp4.mp4` 也可，腳本會自動處理
- 或直接用 **拖放轉錄.bat**

### 視窗一閃就關

在 `demo-workspace` 資料夾網址列輸入 `cmd`，手動輸入 `一鍵轉錄.bat` 看錯誤訊息。
