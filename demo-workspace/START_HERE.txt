Call Coach 本機助手 — 從這裡開始
==============================

【必要條件】需先安裝 Python 3.10 或以上（Windows / Mac 皆可）
  下載：https://www.python.org/downloads/
  Windows 安裝時請勾選「Add python.exe to PATH」

請雙擊以下任一檔案啟動（在這個資料夾內）：

  1. start_call_coach.cmd     ← 請點這個！（類型：Windows 命令指令檔，會出現黑窗）
  2. start_call_coach.pyw     ← 進階用（類型：Python 檔，無黑窗；失敗時可能完全沒反應）

如何分辨：在檔案總管開啟「檢視 → 顯示 → 檔案名稱副檔名」，
  .cmd = 命令指令檔（建議）
  .pyw = Python 檔（不要先點這個）

啟動成功後會自動開啟 Call Coach，請選擇：
  - 開發 · 電訪逐字稿（Vibe 匯出檔）
  - DEMO · 錄影轉逐字稿（本機 MP4 轉錄）

若雙擊 .pyw 完全沒反應：
  → 多半是没裝 Python，或安裝時沒勾 PATH
  → 請改用 start_call_coach.cmd，會顯示錯誤與安裝指引

若仍無法執行：
  - 在資料夾網址列輸入 cmd，執行：python --version
  - 若顯示版本號，再執行：python demo_app.py
