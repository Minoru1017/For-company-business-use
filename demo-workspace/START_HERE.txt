Call Coach 本機助手 — 從這裡開始
==============================

【請點這個檔案啟動】
  → 雙擊「啟動 Call Coach.cmd」
  → 保持黑窗開啟 → Call Coach DEMO → 完整環境安裝

【如何確認是新版（v11.0.2+）】
  ✓ 有「啟動 Call Coach.cmd」和 demo_app.py
  ✓ 有 runtime\python\ 資料夾
  ✗ 沒有 _internal 資料夾（有 _internal = 舊版，請刪除重下）

【若出現 python312.dll 錯誤】
  → 代表您點了 CallCoachAssistant.exe（舊版）
  → 請關閉錯誤視窗，改用「啟動 Call Coach.cmd」
  → 或刪除整個資料夾，至 Releases 重新下載最新 zip
