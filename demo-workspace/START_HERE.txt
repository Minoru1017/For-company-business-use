Call Coach 本機助手 — 從這裡開始
==============================

【Windows 首次使用 — 最簡單】
  雙擊 setup_all.cmd
  → 自動安裝 Python 3.12 + ffmpeg（需 winget）
  → 自動啟動本機助手（黑窗請保持開啟）
  → 回到 Call Coach 網頁，按「完整環境安裝」

【已裝 Python 的用戶】
  雙擊 start_call_coach.cmd（命令指令檔，不是 Python 圖示的 .pyw）

【必要條件】
  Python 3.10+（setup_all.cmd 可自動安裝）
  下載：https://www.python.org/downloads/

啟動成功後會自動開啟 Call Coach，請選擇：
  - 開發 · 電訪逐字稿（Vibe 匯出檔）
  - DEMO · 錄影轉逐字稿（本機 MP4 轉錄）

若雙擊 .pyw 完全沒反應：
  → 請改用 setup_all.cmd 或 start_call_coach.cmd

說明見 README.md
