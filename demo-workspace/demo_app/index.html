DEMO 轉錄助手

把 DEMO 錄影變成逐字稿 · 全程本機處理 · 音檔不上傳雲端

① 環境準備
② Token 設定
③ 選擇錄影
④ 轉錄完成

步驟一：環境準備

第一次使用請按「一鍵安裝」。安裝完成後，下方項目應全部顯示 OK。

    安裝約 5～15 分鐘（需網路下載模型工具）。若缺少 ffmpeg，請在 CMD 執行：winget install Gyan.FFmpeg

    步驟二：設定 Hugging Face Token

    用於辨識「顧問 vs 客戶」誰在說話。Token 只保存在本機 .env，不會上傳。

    1. 註冊帳號：huggingface.co/join
    2. 建立 Read Token：Settings → Access Tokens → New token → Type 選 Read
    3. 同意三個模型授權（各頁按 Agree）： community-1、 diarization-3.1、 segmentation-3.0

    步驟三：選擇 DEMO 錄影並開始轉錄

    建議大檔 DEMO 用手動複製（比瀏覽器拖曳快很多）。

    推薦：手動複製 MP4 到 input 資料夾

    用檔案總管將 MP4 複製到下方路徑，再按「重新掃描」：

    demo-workspace\input

    或透過瀏覽器拖曳（小檔較快；大檔可能需 5～15 分鐘）

    拖曳 MP4 到這裡，或點擊選擇檔案

    2 小時 DEMO 在 CPU 筆電約需 1.5～3 小時，請接電源、關閉其他程式。轉錄中請勿關閉此視窗。

    步驟四：轉錄完成！

    逐字稿已產生在 output\ 資料夾：
