AI 工具：免費能做什麼、付費才能做什麼

主流產品方案與優劣比較 ・ 整理日期 2026-09-10 ・ 定價為美金、以各家官網公開方案為準；用量限額在 2026 年已多次調整，訂閱前請再確認當天數字。
一句話結論：免費層已經夠用來「問問題、寫短文、看圖、搜尋」；付費買的是 用量、旗艦模型、代理式功能（深度研究／寫程式／自動化）、長文件處理。$200 等級的高階方案只適合每天都撞到 $20 方案用量牆的人。

一、免費 vs 付費：跨產品通則

面向免費層普遍能做付費（約 $20/月）才解鎖高階層（$100～300/月）才有
模型中階模型（Flash / Instant / Sonnet 級），尖峰時降級或排隊旗艦模型可自選、推理深度可調「Pro / Heavy / Deep Think」最高推理版
用量每日或每 5 小時一小額配額，聊到一半會被暫停5～10 倍配額、優先通道5～20 倍付費配額，實務上接近不限
上傳／長文檔案上傳有限、上下文 32K～200K上下文 256K～1M、大量上傳最大上下文
深度研究、Agent、影片沒有，或每月幾次試用有，但每月次數有上限次數上限拉到最高
寫程式代理沒有（Codex / Claude Code 皆需付費）有，配額與聊天共用大幅提高配額
資料用於訓練預設會，可手動關閉個人方案仍預設會，可關閉商務／企業方案預設不訓練
廣告部分有（ChatGPT Free / Go）無無

二、通用型 AI 助理逐一比較

ChatGPT（OpenAI）

方案價格內容
Free$0GPT-5.6 Luna 標準對話；有限訊息、上傳、圖片、語音；無 Deep Research、無 Agent；有廣告
Go$8配額加大，但仍有廣告、無進階推理、無 Agent
Plus$20GPT-5.6 Sol 旗艦、Deep Research（約 10 次/月）、Agent 模式、Codex 寫程式、Sora 影片、Custom GPTs、Projects、記憶、無廣告
Pro$100 / $2005 倍／20 倍用量、Sol Pro 推理、最大上下文（400K）、Codex 上限最高
  • 優勢：功能最廣——一個訂閱含影片、代理、寫程式、建站；生態與外掛最多；一般使用者最熟悉。
  • 劣勢：只有 OpenAI 一家模型；最想用的功能（Deep Research、Sora）正是計量最嚴的；四層方案令人困惑；便宜層有廣告。

Claude（Anthropic）

方案價格內容
Free$0Sonnet 級聊天；含網頁搜尋、檔案產生、程式執行、延伸思考、Artifacts、記憶；無 Claude Code、無 Research、無 Projects
Pro$20（年繳 $17）Claude Code、Cowork、Design、Research、無限 Projects、全模型（含 Opus）、Chrome 擴充、Microsoft 365 整合、5 倍用量
Max$100 / $2005 倍／20 倍 Pro 用量、更高輸出上限、尖峰優先、新功能搶先
  • 優勢：寫作品質與程式碼公認最好之一；長文件（1M 上下文）；Claude Code 是目前最強的終端寫程式代理之一；隱私政策較保守。
  • 劣勢：用量牆最有感（5 小時 + 每週雙重限額，Claude Code 燒配額很快）；沒有影片生成；免費層沒有代理功能；只有 Anthropic 模型。

Gemini（Google）

方案價格內容
Free$0Gemini 3.5 Flash（少量 3.1 Pro）、多模態、Gemini Live、15 GB 雲端、上下文 32K
AI Plus$4.99～7.99最便宜入門：2 倍用量、128K 上下文、Gmail/Docs 內 AI、200～400 GB 儲存、NotebookLM
AI Pro$19.99Gemini 3.1 Pro、1M 上下文、Deep Research、Veo 影片、2～5 TB 儲存、YouTube Premium Lite
AI Ultra$99.99～199.99Deep Think 推理、5～20 倍用量、Gemini Spark 代理、20 TB
  • 優勢：CP 值最高（同價附大量雲端與 Workspace 整合）；免費層上下文與多模態強；有最便宜的付費入門；深度用 Gmail/Docs/Sheets 的人幾乎沒有第二選擇。
  • 劣勢：用量上限寫得最模糊；免費層只有 32K 上下文；寫程式代理較弱；產品線改名頻繁。

Microsoft Copilot

方案價格內容
Free$0Windows / Edge / 網頁內建，每日提示次數有上限
個人付費$19.99獨立 Copilot Pro 已於 2026/8 停售；只剩 Microsoft 365 Premium（含 Office 全套 + 6 TB + 進階 Copilot）
企業約 $18～21/人/月M365 Copilot Business：Word / Excel / Teams 內嵌
  • 優勢：公司電腦通常已經有；資料留在租戶內，IT 最容易接受；Office 內嵌無需切換。
  • 劣勢：底層是 OpenAI 模型但常落後一代；個人版必須連 Office 一起買；獨立功能面最窄。

Perplexity

五、怎麼選（依公司情境）

情境建議
業務同事，只需問問題、整理文件免費 Gemini 或 ChatGPT Free 就夠；公司已有 M365 就直接用 Copilot，最不會被 IT 擋
一個人要付一份 $20寫作與長文件多 → Claude Pro；功能要最廣 → ChatGPT Plus；活在 Google 生態 → AI Pro（附 2～5 TB 最划算）；主要做查證研究 → Perplexity Pro
DEMO 錄影轉錄不能上雲的客戶案子用本機 WhisperX；日常量大走 Azure Fast Transcription（一小時 DEMO 約台幣 30～40 元），用 team-config.env 集中管理金鑰
不建議買$200 等級個人方案（除非天天撞 $20 方案用量牆）；Grok 用在公司環境；已停售的 Copilot Pro
共通陷阱：個人方案預設會把對話拿去訓練模型，要自己到設定關掉；客戶資料請走商務／企業方案或本機模型。各家限額 2026 年已調整多次，訂閱前看一次官網當天的數字。
