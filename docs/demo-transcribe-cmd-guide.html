DEMO 錄影轉逐字稿

CMD 命令提示字元操作手冊｜全程本機處理，音檔不上傳雲端
適用：1～2 小時 DEMO 錄影（MP4）→ 逐字稿（SRT）→ Sales Call Coach 分析

你需要準備：
  • 已安裝 Python、ffmpeg、WhisperX（.venv 資料夾）
  • .env 內已填入 Hugging Face Token
  • DEMO 錄影檔（MP4）放入 input\ 資料夾

一、整體流程（一張圖看懂）

DEMO 錄影 MP4
↓ 放入 input 資料夾
↓ CMD 執行轉錄指令
↓ 等待 1.5～3 小時（請接電源）
↓ 到 output 資料夾取 .srt
↓ 上傳 Sales Call Coach 分析

二、資料夾結構

C:\Users\你的帳號\demo-workspace\
├── .env              ← Token 設定檔（勿分享）
├── .venv\            ← 轉錄程式（自動建立）
│   └── Scripts\
│       └── whisperx.exe   ← ★ 轉錄時要用這個
├── models\           ← AI 模型快取（約 3～6 GB）
├── input\            ← ★ 把 MP4 放這裡
│   └── demo.mp4
└── output\           ← ★ 轉好的 SRT 在這裡
⚠ 常見錯誤： 路徑要寫 .venv\Scripts\whisperx.exe，不是 Scripts\whisperx.exe（少了 .venv\ 會找不到檔案）。

三、如何開啟 CMD（命令提示字元）

1
開啟檔案總管，進入 demo-workspace 資料夾
2
點一下上方網址列（顯示路徑的那一行）
3
輸入 cmd，按 Enter
4
出現黑底白字視窗，即為 CMD（轉錄過程不要關閉）

四、第一次使用（只需做一次）

4-1 安裝 Python（若尚未安裝）

下載：https://www.python.org/downloads/
安裝時務必勾選 Add python.exe to PATH，裝完重開電腦。

4-2 安裝 ffmpeg

winget install Gyan.FFmpeg

4-3 建立虛擬環境並安裝 WhisperX

cd /d C:\Users\你的帳號\demo-workspace

python -m venv .venv

.venv\Scripts\python.exe -m pip install -U pip wheel

.venv\Scripts\python.exe -m pip install whisperx

4-4 設定 Hugging Face Token

用記事本開啟 .env，填入（等號前後不要空格）：

HF_TOKEN=hf_你的token

並到 Hugging Face 同意以下三個模型授權（同一帳號）：

  • pyannote/speaker-diarization-community-1
  • pyannote/speaker-diarization-3.1
  • pyannote/segmentation-3.0

五、每次轉 DEMO（重點！複製貼上即可）

步驟 1：放入錄影

將 MP4 複製到 input\ 資料夾。建議檔名：demo.mp4

若檔名變成 demo.mp4.mp4（雙副檔名），請重新命名為 demo.mp4，或將下方指令中的檔名改成實際檔名。

步驟 2：開啟 CMD 並進入資料夾

cd /d C:\Users\你的帳號\demo-workspace

（把「你的帳號」改成你的 Windows 使用者名稱，例如 經銷業務）

步驟 3：設定環境並讀取 Token

set HF_HOME=%CD%\models
set HUGGINGFACE_HUB_CACHE=%CD%\models\hub

for /f "usebackq tokens=1,* delims==" %a in (".env") do if /i "%a"=="HF_TOKEN" set HF_TOKEN=%b

步驟 4：從 MP4 抽出音軌（約 1～3 分鐘）

ffmpeg -y -i input\demo.mp4 -vn -ac 1 -ar 16000 -c:a pcm_s16le input\demo.wav

若已有 demo.wav 可跳過此步驟。

步驟 5：開始轉錄（最久，請接電源）

.venv\Scripts\whisperx.exe input\demo.wav --model medium --language zh --device cpu --compute_type int8 --threads 8 --batch_size 4 --diarize --hf_token %HF_TOKEN% --min_speakers 2 --max_speakers 2 --output_format srt --output_dir output
預估時間（Intel 內顯 CPU 筆電）：
2 小時 DEMO 約需 1.5～3 小時。轉錄中請接電源、關閉不必要的程式。

步驟 6：確認結果

dir output\*.srt

到 output\ 資料夾取得 .srt 檔。

六、上傳 Sales Call Coach

  1. 開啟網址：https://minoru1017.github.io/For-company-business-use/
  2. 上傳 output\ 內的 .srt 檔
  3. 確認 SPEAKER_00＝顧問、SPEAKER_01＝客戶
  4. 若兩者對調 → 點「全部互換」
  5. Tab 微調少數錯誤 → 按「開始分析」

七、一頁速查（每次轉錄複製這段）

八、常見問題

錯誤訊息原因解法
系統找不到指定的路徑 路徑寫錯 確認是 .venv\Scripts\whisperx.exe（有 .venv\）
找不到 demo.mp4 MP4 不在 input 資料夾 把錄影放入 input\，或檢查檔名是否為 demo.mp4.mp4
gated repo / Please log in Token 無效或未授權 檢查 .env 的 HF_TOKEN；同意三個 pyannote 模型；重建 Token
找不到 python Python 未安裝或未加 PATH 重新安裝 Python 並勾選 Add to PATH
.bat 無法執行 公司電腦封鎖批次檔 改用本手冊的 CMD 指令（不用 .bat）

九、隱私提醒

  • DEMO 錄影與逐字稿存放於公司受控位置，勿上傳個人雲端
  • 勿將 .env（Token）或客戶逐字稿分享至公開場合
  • 使用 Call Coach 的 Gemini 分析前，請先去識別化並勾選同意
  • 刪除整個 demo-workspace 資料夾即可完全移除本工具
