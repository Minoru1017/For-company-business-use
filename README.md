# Sales Call Coach

顧問式銷售電訪逐字稿分析工具（VER 11）。

## 線上使用

**https://minoru1017.github.io/For-company-business-use/**

開啟後選擇工作流程：
- **開發 · 電訪**：直接丟錄音檔（m4a / mp3 / wav…）由 AI 轉錄，或上傳 Vibe 匯出的 `.vibe.json`／SRT
- **DEMO · 錄影**：本機轉錄 1～2 小時 MP4（需啟動 `demo-workspace`）
- **開發 · 陪練**：臨場反應訓練——客戶接起電話，你主動問、限時接話（`#drill`）
- **開發 · 症狀**：每天的漏斗、當天的錄音、跨通共同病症、明天只改一個動作（`#log`）

## 開發症狀紀錄

純瀏覽器版：錄音、逐字稿、漏斗數字與筆記都存在**這台電腦的瀏覽器**（IndexedDB），只有轉錄與 AI 診斷才會把資料送到你選的引擎。

1. **日曆**點一天 → 填當天漏斗：撥出／接通／超過 N 分／長 Call（≥ M 分）／進邀約。N、M 可在「門檻設定」改（預設 5／15）；「超過 N 分」與「長 Call」留空會依匯入錄音的長度自動算，手填會覆蓋
2. **匯入公司電話系統匯出的 wav／mp3**（可多檔、可拖放）。檔名含日期（`20260923_1430_0912xxx.wav`、`2026-09-23 14-30-12.wav`、`rec_2026.09.23_1430.wav`…）會自動歸到那一天，否則用檔案修改時間，再否則歸到目前選的日期；重複檔略過
3. 點檔名直接**播放**；「全選」後按**批次分析所選**：尚未轉錄的先轉錄（Gemini 或新竹 Worker，沿用「開發 · 電訪」／DEMO 填過的設定；每次批次都要重新勾選同意），已轉錄的只在本機重跑規則分析
4. **共同病症**：客戶說話比例、客戶第一次說出困擾的分鐘、第一次提方案的分鐘、業務問句、五層平均，加上 20 種症狀的出現次數／通、最多 3 句原話證據、「連續第 N 天」
5. **AI 診斷**（可選）：只送當天彙總數字、症狀次數與少量原話——不送整份逐字稿、不送錄音——回傳核心病症 ≤ 3、整體模式、「只改一件事」（可一鍵帶入筆記）
6. **改善筆記**：今天看到的病症 → 明天只改一個動作 → 怎麼驗證 → 自由筆記，自動儲存；隔天會提醒「昨天你說要改的動作」
7. 每通可「完整分析」→ 載入既有的標記 → 分析流程；「刪錄音」可只刪音檔、保留逐字稿與分析

清除瀏覽器網站資料會一併刪除紀錄；換電腦不會帶著走。

### 綁定 Google 試算表（自評病症）

如果你已經有一張「橫軸病症、縱軸日期、格子填有」的試算表，可以在「Google 試算表同步」把它接進來：

- **讀**：只要試算表共用設定是「知道連結的使用者可檢視」，網頁會直接讀 CSV，把第 1 列的病症名稱變成當天的「自評病症」勾選清單、沒有標題的那欄視為「昨天說要改的動作有沒有做到」，日曆與近 7 天也會標出自評。新增或改名欄位不用改程式。
- **寫**（選用）：在試算表「擴充功能 → Apps Script」貼上網頁裡提供的程式碼、部署成網頁應用程式（執行身分「我」、存取權「所有人」），把 `/exec` 網址與 Token 填回來。之後在網頁勾選會**直接寫回同一格**（有／無），「有沒有做到」寫回同一欄，「把今天的漏斗＋筆記寫入試算表」會在右側自動建立 撥出／接通／超過5分／長Call／進邀約／工具偵測病症／明天只改一個動作 七欄。試算表裡沒有的日期會自動補一列。
- AI 診斷會把自評病症與「有沒有做到」一起送去對照（自評 vs 錄音偵測是否一致）。
- 沒有 Apps Script 時是唯讀，仍可看、不能勾。

## 開發電訪 · 直接上傳錄音檔

不想先經過 Vibe，可以把錄音檔直接丟進「開發 · 電訪」的「直接上傳錄音檔」面板，轉錄完會自動標好業務／客戶並進入標記 → 分析：

- **Gemini 雲端轉錄（預設）**：只要 Gemini API Key（與 AI 深度分析共用）。≤ 14 MB 隨請求送出；更大的檔會先暫存到 Gemini Files，轉錄完即刪除。單檔建議 60 分鐘內，太長時輸出可能被截斷（會提示「僅取得前段」）。
- **新竹 GPU Worker（不出 Google）**：填 Worker 網址與 Token，錄音直傳自己的主機用 WhisperX 轉錄；架設方式同 DEMO 遠端主機。
- 兩種方式**每次上傳都要重新勾選知情同意**；敏感內容請先去識別化。已有逐字稿仍走原本 Vibe／SRT 路徑，全程在本機解析。

## 電訪開發 · 臨場陪練

練的是「不慌、不亂套話、不講不出話」，不是被動看 AI 分析。

1. 選誰接電話（盲抽或 5 個劇本：要／怕／想／愛／爽 各一，分級與適配都是隱藏的）、每句限時（15／30／45 秒）、突襲頻率
2. 撥號後客戶先開口，你打字或用麥克風回答；**通話中沒有任何提示**
3. 客戶依你的問題回應：問到哪一層就透露哪一層；問太籠統只給敷衍回答；
   罐頭話術、恐嚇、太早推方案、問錯分級方向會被當場打回（耐心值下降，耗盡就掛電話）
4. 每隔幾句丟一次突襲（費用、跟免費教學差在哪、沉默…），下一句要接住（承認→反問）
5. 限時內沒開口算「卡住」，連續兩次客戶掛電話
6. 掛電話後先憑印象判斷分級與適配 → 看回饋：臨場分數、平均反應秒數、每句判定、做得好／待加強 → 一鍵送進完整分析（六步驟／五層／五字口訣）
7. 「複製陪練紀錄」可拿去和資深夥伴討論修正

離線劇本不需網路；「Gemini AI 客戶」用同一套劇本、由模型改寫成更像真人的口吻（共用下方 AI 深度分析的 Key 與額度）。

## 本機 DEMO 轉錄

1. 下載 `demo-workspace` 資料夾
2. 雙擊 `start_call_coach.pyw`
3. 在 Call Coach 選擇 **DEMO · 錄影轉逐字稿**

轉錄期間會顯示「現在在哪個階段、幾 %、還要多久、預計幾點完成」，分頁標題也會跟著跑；可以先去做別的事，按「完成時通知我」會在完成時播提示音並發桌面通知。關掉分頁再回來會自動接上進度。

轉錄模式三選一：**本機**（CPU，音訊不出電腦）、**Azure 雲端**（免安裝、2～5 分鐘）、**遠端主機**（借用自己家裡有 NVIDIA 顯卡的電腦當 Worker，48 分鐘約 3～8 分鐘、`large-v3` 最準，音訊不經第三方）。遠端主機的架設方式見 [demo-workspace/README.md](demo-workspace/README.md#最快路徑遠端主機轉錄借用自己的-gpu-電腦)。

## 把結果帶走

分析完成後，第 10 區「把結果帶走」提供：

- 複製摘要（LINE／Slack）：一則訊息看完這通電話的健康度與下一步
- 複製「下一通要問」清單：把建議話術整理成 `☐` 清單
- 下載報告 `.md`（放 Notion／Obsidian）、下載已標記逐字稿 `.srt`（下次載入不用重標）、列印／存成 PDF
- 助手在線時：一鍵存到助手 `output/` 資料夾（與 SRT 放一起）

分析過的通話會自動留在「最近分析」（只存在這台電腦的瀏覽器，最多 20 筆），可一鍵回看重跑。

## 功能

- 模式選擇：電訪分析 / DEMO 本機轉錄 / 臨場陪練
- 本機規則引擎：六步驟、五層資訊、適配判斷
- 信任感規則：客戶揭露層級（敷衍→事實→困擾→私人）與「信任突破」話點；業務先給／事實題／給退路／被否認退一步／不催不審檢核；偵測「搖擺型」客戶（需求可有可無、不缺錢時間）並提示用想／愛／爽試探或敢判 C
- 臨場反應陪練：隱藏分級的客戶劇本、限時接話、突襲、套話／恐嚇／太早推偵測，結束後接完整分析
- DEMO 轉錄整合：WhisperX 本機轉錄 → 自動載入 SRT；等待可預期（階段／百分比／預計完成時間／完成通知）；可切到 Azure 雲端或自己的遠端 GPU 主機（Worker 模式）
- 產出進工作流：LINE／Slack 摘要、下一通清單、`.md`／已標記 `.srt`、列印 PDF、存到助手 output、最近分析回看
- 選用 Gemini AI 深度分析

## 安全與隱私

- DEMO 音檔全程本機處理，不上傳
- 本機 API 需工作階段 Token，且僅允許 Call Coach 官方來源跨域存取
- HF Token 不寫入程序參數或日誌；`.env` 權限設為僅本機使用者可讀
- Gemini API Key 預設僅保留在本次瀏覽器分頁（需勾選才記住）
- AI 分析前需勾選同意傳送至 Google
